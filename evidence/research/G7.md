# G7: harness-level incidents and CVEs disclosed 2026-01-01 to 2026-10-15

Access date 2026-10-15. Files: `evidence/incidents.d/G7.csv` (118 rows, 112 verified=yes), `evidence/ledger.d/G7.csv` (133 rows), `evidence/sources_G7.bib`.

## Method
- GHSA: `gh api repos/OWNER/REPO/security-advisories` for ~45 harness, MCP and editor repos, plus `gh api /advisories?ecosystem=&affects=` for npm/pip packages and `type=malware` listings.
- NVD API v2 keyword + monthly pubDate windows (Claude Code, Codex, Gemini CLI, Cursor, OpenClaw, OpenCode, Cline, Kilo, Roo, Qwen Code, MCP, Windsurf, Copilot, OpenHands). Note: NVD results were NOT paginated beyond 200 per keyword-month, and keyword hits are noisy (Cursor/Codex hit database cursors, WordPress themes). MCP and OpenClaw are therefore sampled, not enumerated.
- CVE.org (cveawg.mitre.org) record read where NVD was rate-limited or the CNA is not GitHub.
- Vendor bulletins read: AWS 2026-001, 009 (404), 035, 037, 074, 117; Check Point (2026-02-25); Pillar; Intezer; Anthropic Sept 2026 threat report; researcher write-ups (oddguan.com x2, cereblab gist, Mend).
- Conventions: `date_disclosed` = repo-advisory published date (GHSA) or bulletin/CVE-record date. NVD and global-GHSA dates differ by days to weeks for the same issue (noted per row). `fix_date` = npm/PyPI publish time (or GitHub release) of the fixed version, only when that registry lookup succeeded. `patch_latency_days` = fix_date minus date_disclosed; **negative means the fix shipped before the advisory** (the normal pattern for vendor-coordinated GHSAs). 55 rows have a latency; median -21 days, Claude Code rows median -47 days. Latency is NOT time-from-report, which is mostly undocumented.
- No undisclosed vulnerability found; no private/DISCLOSURE_DRAFT.md entry.

## Trends 2026 vs 2025
1. **Disclosure channel shift**: 2025 seed list is dominated by researcher blogs/press (Invariant, Tracebit, Cymulate, Pillar). 2026 is GHSA/CVE-first: Anthropic, Cursor, Zed, VS Code, AWS and OpenAI (as CNA, Sept) now publish per-issue advisories; many harness bugs reach 5 to 10 advisories in one day (Claude Code Feb 3/6; OpenClaw Sept 11; mcp-atlassian Jul 10; VS Code Sept 8 and Oct 13). Counting CVEs per harness now mostly measures advisory policy, not security. Do not compare raw counts across vendors in RQ3.
2. **Fix-before-advisory is normal** (median -21 days); advisories lag fixes by weeks to months for vendors with auto-update (Claude Code up to -153 days). Latency from report is rarely public.
3. **Repo-controlled config before consent (T02/RC2) persists as the top agent-specific class** (Claude Code 21852/33068/40068, Gemini 13745, Codex 61260, Pi 54325, Zed 44465, Cursor 48124/63093, Kiro, VS Code 78462). Variants: trust-dialog logic bypassed by forged git metadata (worktree commondir).
4. **New 2026 classes** (not in MISSION seed list):
   - **Git-config-as-RCE** (`core.fsmonitor`, `core.hooksPath`, `attr.tree` filters, bare repos nested in project): Copilot CLI, Codex CLI/Desktop, Goose, Zed, Claude Code worktrees, Cursor `.git` hooks. Proposed new linter rule family and fixture set.
   - **Windows uncontrolled search path** (`git.exe` planted in project): Claude Desktop 88066, Cursor 63093, Kiro 18656/18657.
   - **Command-approval parser differentials** (shell quoting/expansion/redirect/PowerShell `--%`/newline): Roo Code family, Copilot CLI, Zed, OpenClaw, Codex, Claude Code (sed, find, ZSH clobber). Allowlists remain the weakest control; rules should prefer deny + sandbox.
   - **Sandbox escape through the harness's own unsandboxed half** (symlink/worktree/venv/cwd): Claude Code, Cursor "DuneSlide".
   - **Local control plane / DNS-rebinding / cross-origin WebSocket** (RC4): OpenCode, Cline kanban/hub, Hermes, DSH, Python SDK WS transport, Windsurf-class MCP rewrites, MCPJam, Windows-MCP. Default `autoApprove` on those sessions turns CSRF into RCE.
   - **Harness vendor data upload** (Grok Build) and **self-modifying trust boundary** (agent writes its own MCP/hook config: Kiro mcp.json, Claude Code settings.json, Kiro global config, Cursor reading Claude hooks).
   - **Agent-config-aware supply-chain worms** that read or write `.claude/`, `.cursor/`, `.gemini/`, `.kiro/` files (Bitwarden CLI, Miasma): T05/T06/T10 overlap.
   - **MCP OAuth credential misdirection** and **registry provenance** bugs (SDKs, MCP Registry).
   - **Marketplace pin bypass** (Claude Code plugins CVE-2026-86063) and skill-marketplace malware (ClawHub).
5. **Misuse (T16)** moved from 2025 "vibe hacking" anecdotes to Anthropic reporting agentic coding as an operational orchestration layer; keep descriptive.
