### Devin (CLI + cloud)
Devin CLI ("Devin for Terminal", binary `devin`, v3000.11.3) is a closed-source binary (implementation language unverified); also a cloud agent at app.devin.ai. `devin --cloud` hands off.
Key security points: modes `normal|accept-edits|smart|dangerous(yolo,bypass)|autonomous`; org deny/ask cannot be overridden; `--sandbox` (Seatbelt / bwrap+seccomp) off by default, "research preview/unstable"; workspace trust default true and `-p` fails in untrusted dirs (CI must pass `--respect-workspace-trust false`, a footgun to lint); CLI imports Claude/Cursor/Windsurf/OpenCode/Zed configs by default (`read_config_from.*` = true), including `.claude/settings.json` hooks, so an untrusted repo with `.claude/settings.json` hooks or `.cursor/mcp.json` influences Devin.
