\begin{abstract}
Coding agents are built as \emph{model plus harness}: the runtime loop that holds credentials, runs shell commands, mounts Model Context Protocol (MCP) servers, reads repository configuration, spawns sub-agents and runs headless in CI. We study the security of this deterministic layer across \nHarnesses{} harnesses and runtimes in four method tiers: open source (white-box), closed but runnable (black-box), closed and unreachable (documentation only), and SDK runtimes. We contribute: (i)~a threat taxonomy (T01--T19) mapped to STRIDE, MITRE ATLAS and the OWASP LLM, Agentic and MCP lists (RQ1); (ii)~a 15-dimension control matrix with \nCellsScored{} evidence-linked scores and a second LLM-agent rating on the same fact base (quadratic $\kappa=\kappaEOne$) (RQ2); (iii)~a survey of \nIncCounted{} publicly disclosed harness-level advisories and incidents from 2025--2026: in \pctRCTwoThree{} the root cause is a flawed approval, allowlist or path check or configuration honoured before consent, while pure prompt injection, the residual class of our procedure, is \pctRCOne{} (RQ3); (iv)~\tool{}, an open-source auditor with micro precision \eSixPrecision{} (95\% CI \eSixPrecisionLo--\eSixPrecisionHi) on a held-out synthetic corpus and a stratified prevalence study of \eTwoReposAudited{} public repositories (RQ4); (v)~an inert canary benchmark (\nBenchRuns{} runs, one small local model) that found no detectable difference in injection-following between permission modes but showed a documented Claude Code import feature placing a gitignored secret in the session transcript in \benchClaudeImportK{} of \benchClaudeImportN{} runs (RQ5); (vi)~a governance checklist mapped to NIST AI RMF, ISO/IEC~42001, OWASP and the MAS AI risk-management guidelines (RQ6); and (vii)~a black-box comparison of vendor claims with observed behaviour, where \pctClaimsTested{} of \nClaims{} documented claims were testable headless and \nClaimsMatch{} of the \nClaimsTested{} tested matched (RQ7). Every result number is generated from versioned results files.
\end{abstract}
