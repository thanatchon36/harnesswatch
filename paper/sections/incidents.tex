\section{Incident and CVE Survey, 2025--2026}\label{sec:incidents}
\answers{RQ3}

\paragraph*{Collection and counting rule} We searched NVD, the GitHub Advisory Database, vendor security pages and researcher write-ups for harness-level incidents disclosed from January 2025 to mid-October 2026 (including the harnesses' MCP servers, SDKs, CI actions and distribution channels), yielding \nIncRows{} rows after deterministic de-duplication. An incident is \emph{counted} only if (a)~its primary source was read and (b)~an independent script re-resolved every listed CVE and GHSA identifier against NVD and the GitHub advisory API; incidents without an identifier need a primary vendor or researcher source. \nIncNotVerified{} rows failed (a), \nIncIdFailed{} failed (b) and \nIncOutside{} fell outside 2025--2026, leaving \nIncCounted{} incidents (\nIncTwentyFive{} disclosed in 2025, \nIncTwentySix{} in 2026; \nIncCVE{} with a CVE and \nIncGHSA{} with a GHSA). By kind, \nIncVuln{} are vulnerabilities, \nIncDesign{} design weaknesses, \nIncSupply{} supply-chain compromises, \nIncMisuse{} documented offensive misuse and \nIncEvent{} other events. Classes follow Section~\ref{sec:threats}; one LLM agent classified every incident, and inter-rater agreement for classes and root causes was not measured. The population is selected for disclosed, harness-level software defects, including \nIncTierEco{} ecosystem items such as MCP tooling and package compromises, so shares describe that population, not the distribution of real-world harm.

\paragraph*{Timeline} Disclosures rose through every full quarter of the study period (Figure~\ref{fig:timeline}). This reflects more harnesses, more researcher attention, wider GHSA use and an agent-assisted search that favours recent, well-indexed advisories, not necessarily declining quality; likewise, per-product counts track scrutiny and disclosure maturity (D15) as much as risk, so we do not rank products by them.

\paragraph*{Root causes} Table~\ref{tab:rootcauses} gives the distribution. Defective checks that gate an agent capability (RC3: allowlists bypassed by shell substitution, redirections, environment-variable prefixes, \texttt{find -exec}, symlinks or lookalike domains) are the largest group with \nIncRCThree{} incidents (\pctRCThree{}). Configuration honoured before consent (RC2) adds \nIncRCTwo{}: repository settings, hooks, \texttt{.env} files, MCP declarations and Git configuration that run or take effect before the trust prompt. Together these deterministic harness defects account for \pctRCTwoThree{} of counted incidents, the largest share but not a majority. Conventional defects not specific to agents (RC10) account for \pctRCTen{}, and missing authentication or Origin checks on local control endpoints (RC4) for \nIncRCFour{}. Pure prompt injection with no other control failure (RC1) is \pctRCOne{}; as the residual class, this is a lower bound on injection's role, which we did not code separately as a vector.

\paragraph*{Classes} By primary class (Table~\ref{tab:taxonomy}), permission-model weaknesses (T03, \nIncTopThree{}, \pctTopThree{}) and repository configuration as code execution (T02, \nIncTopTwo{}) lead, followed by conventional defects (T19, \nIncTNineteen{}) and control-plane exposure (T18, \nIncTEighteen{}). Indirect prompt injection is the primary class of only \nIncTOne{} incidents, although injection is the delivery vector in many incidents classified elsewhere.

\paragraph*{Representative cases} (credit to the original researchers) \emph{Injection to configuration:} hidden Unicode in rules files (Pillar Security)\evTP~\cite{pillar2025rulesfile}; injection flipping Copilot's auto-approve (CVE-2025-53773)\evTP~\cite{etr2025copilot}; Cursor executing attacker-written or silently modified MCP configuration (CVE-2025-54135/54136)\evD\evTP~\cite{cursor_54135,checkpoint2025mcpoison}. \emph{Configuration before consent:} Claude Code project files running code and sending API tokens before the trust dialog (CVE-2025-59536, CVE-2026-21852)\evTP~\cite{checkpoint2026claude}; Codex CLI loading project MCP servers without confirmation (CVE-2025-61260)\evTP~\cite{checkpoint2025codex}; Gemini CLI's CI action auto-trusting the workspace\evD~\cite{ghsa_gemini_action}. \emph{Allowlist and path checks:} Gemini CLI command deception\evTP~\cite{tracebit2025gemini}; Claude Code path and command bypasses (CVE-2025-54794/54795)\evTP~\cite{cymulate2025inverse} and deny rules not enforced through symlinks\evD~\cite{ghsa_cc_symlink}. \emph{MCP:} tool poisoning and the GitHub MCP leak (Invariant Labs)\evTP~\cite{invariant2025toolpoisoning,invariant2025github}, SQL-returned injection via Supabase MCP\evTP~\cite{generalanalysis2025supabase}, MCP Inspector's unauthenticated proxy (CVE-2025-49596)\evD\evTP~\cite{mcp_inspector_49596,oligo2025inspector}. \emph{Other:} unauthenticated local control planes in OpenCode and DeepSeek Harness\evD~\cite{ghsa_opencode_server,ghsa_dsh_host}; a malicious prompt in Amazon Q Developer 1.84.0\evD~\cite{amazonq2025}; the \texttt{nx} ``s1ngularity'' compromise using installed AI CLIs to hunt secrets\evD~\cite{nx2025s1ngularity}; Antigravity data leaks after launch\evTP~\cite{promptarmor2025antigravity,etr2025antigravity}; and a vendor's own account of criminal misuse of a coding agent~\cite{anthropic2025aug}.

\paragraph*{Fix date relative to advisory publication} For the \nLatency{} counted incidents with both dates, a fix release existed on or before the advisory's publication in \nLatencyBefore{} cases (median offset \nLatencyMedian{} days, maximum \nLatencyMax{}); \nIncNoFixDate{} incidents have no recorded fix date (unfixed or unknown). Because advisories are usually published after a fix by design, this measures disclosure practice, not time-to-fix; report dates were not available.
