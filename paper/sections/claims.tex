\section{Documented Claims versus Observed Behaviour}\label{sec:claims}
\answers{RQ7}

\paragraph*{Method} For each Tier-B harness we extracted security-relevant statements from the vendor's documentation into a claims table (\nClaims{} claims across the closed harnesses), each tagged with a dimension (telemetry, updates, configuration/hook/MCP trust, sandbox, secret storage, permission default, state-directory modes). We then wrote \nProbes{} black-box probes using the method of Section~\ref{sec:method}. Each probe runs the pinned client in a fresh container, optionally on a synthetic repository seeded with a hook, MCP server or settings file. Verdicts are \emph{match}, \emph{partial}, \emph{mismatch} or \emph{not observed} (behaviour not exercised); claims needing a login, GUI or interactive session stay \emph{untested}.

\paragraph*{Results} Only \pctClaimsTested{} of the \nClaims{} claims could be tested headless without a vendor login; \nClaimsTested{} were tested: \nClaimsMatch{} matched, \nClaimsPartial{} were partial, \nClaimsMismatch{} mismatched and \nClaimsNotObserved{} were not observed; \nClaimsUntested{} remain untested (Table~\ref{tab:claims}). By harness, \nClaimsMatchClaude{} of \nClaimsTestedClaude{} tested Claude Code claims matched, \nClaimsMatchAntigravity{} of \nClaimsTestedAntigravity{} for Antigravity, \nClaimsMatchGrok{} of \nClaimsTestedGrok{} for Grok Build and \nClaimsMatchCopilot{} of \nClaimsTestedCopilot{} for Copilot CLI. All observations in the table are \evT{}; all claims are \evD{}.

\paragraph*{What the probes show} The tested claims are a convenience sample weighted towards network and update behaviour, so the match count does not generalise to the untested claims. The notable findings are documented design properties, not vulnerabilities.
(i)~\emph{Headless trust.} In Claude Code, a \texttt{claude -p} run in a never-trusted folder executed a repository \texttt{SessionStart} hook and started a repository stdio MCP server without a prompt\evT\evD~\cite{cc_permissions_trust}, and applied a repository \texttt{env} entry redirecting the model endpoint\evT\evD{}; \texttt{--bare} prevented the hook\evT\evD~\cite{cc_headless}, and a repository request for \texttt{bypassPermissions} was ignored\evT\evD{}. Its documented \texttt{@path} import in \texttt{CLAUDE.md} also fired on the token \texttt{@.env} inside a shell command line, pulling the gitignored \texttt{.env} into the session transcript (mode 0600) with no model call\evT\evD{}; this explains the E3 secret-in-state result (Section~\ref{sec:eval-bench}).
(ii)~\emph{Trust-gated alternatives.} Grok Build did not run an untrusted repository hook, including one imported from the Claude Code format, and ran it after \texttt{--trust}\evT\evD~\cite{grokbuild_hooks}. Copilot CLI did not start a repository MCP server or hook in an untrusted folder\evT\evD{}, but we did not re-test it in a trusted folder, so ``did not run'' may also mean ``not supported under \texttt{-p}''.
(iii)~\emph{Network.} With documented opt-outs and a local model, Copilot CLI, Grok Build and Claude Code contacted no vendor host\evT\evD{}. Before login, Antigravity's CLI contacted its auto-updater and a telemetry host, as its defaults document, and the updater opt-out worked\evT\evD~\cite{ag_settings}.
(iv)~\emph{The one mismatch} is functional: \texttt{agy -p /help} is documented to run without an agent turn but required authentication\evT\evD~\cite{ag_cli_headless}. \emph{Partial} verdicts concern state-directory modes and MCP start-up before trust, where documentation is silent.

\paragraph*{Limits} A \emph{match} holds for this version in a headless Linux container; it does not certify interactive use, other platforms or post-login behaviour, and without payload inspection it says nothing about what an allowed host receives. Probe effort was uneven (\nClaimsTestedClaude{} Claude Code claims against \nClaimsTestedCopilot{} for Copilot CLI), and Claude Code ran in a configuration its vendor does not support (Section~\ref{sec:method}). Without the opt-outs, during E3, the proxy blocked attempts to reach vendor or telemetry hosts from Claude Code (\texttt{api.anthropic.com}), Codex CLI (\texttt{chatgpt.com}, \texttt{github.com}), Qwen Code (an Aliyun RUM host, \texttt{models.dev}) and OpenCode (\texttt{models.opencode.ai})\evT{}.
