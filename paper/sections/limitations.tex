\section{Limitations and Threats to Validity}\label{sec:limits}
\answers{how far the answers to RQ1--RQ7 generalise}

\paragraph*{Version drift} Scores, probes and bench cells refer to the versions in \texttt{VERSIONS.md}, accessed 15~October 2026. Harnesses release weekly and several were renamed or discontinued during the study; the matrix should be re-run, not cited as current.

\paragraph*{Models and compute} No vendor API keys or logins were used, so the bench runs one small local open-weight model through documented custom-endpoint features and says nothing about any vendor's flagship model. The GPU is shared with the owner's other work; a planned second model family was cancelled to release it, so the goal of at least two models per harness is \emph{not met}, and the scenario set and run count per cell were reduced, leaving wide intervals. A model this small also limits how often any injection is acted on at all. Claude Code was routed to a non-Claude model, which its vendor does not support, and in that setup its default arm is the classifier \texttt{auto} mode; its bench and permission results describe harness behaviour in an unsupported configuration.

\paragraph*{Headless only} Probes and bench runs are headless. Interactive trust dialogs, IDE extensions and GUI-only products (e.g.\ the Antigravity IDE) were not tested; a harness whose interactive mode is safer is under-credited, which is the conservative error for CI use.

\paragraph*{Benign-canary ceiling} Payloads are inert and plainly worded; disguised or adaptive attacks may succeed where they fail, so bench rates are lower bounds.

\paragraph*{Black-box limits} Without TLS inspection we cannot say what an allowed host receives; login-gated harnesses were observed only before login.

\paragraph*{Rating and classification} Evidence collection, both matrix raters, incident collection and incident classification were LLM agents supervised by the author. Both raters worked from one shared fact base, so $\kappa$ measures rubric application, not evidence reliability, and it excludes the N/A-versus-score cells (all \nDisagreeEOne{} disagreements, including those, are published). Incident classes and root causes had a single rater with no agreement measurement, and RC1 is the residual class of an ordered procedure. Several scores depend on rubric interpretations, notably classifier-gated defaults.

\paragraph*{Selection} The incident survey admits only publicly disclosed, harness-level advisories, mostly with CVE or GHSA identifiers; model-level failures are rarely tracked this way, and agent-assisted search favours recent, well-indexed advisories. RQ3 shares therefore describe disclosed harness defects, not overall risk.

\paragraph*{Corpora} E6 is synthetic and author-labelled; E2's code-search sample favours popular, recently indexed repositories; E5 has one session per condition.
